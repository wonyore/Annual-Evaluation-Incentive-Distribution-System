# 年度评价与激励分配系统用户手册

## 1. 系统概述

### 1.1 系统简介

年度评价与激励分配系统是一款专为企业和团队设计的绩效考核与奖金分配管理工具，通过多维度评价体系和灵活的激励计算方法，实现公平、透明的年度评价与奖金分配流程。

### 1.2 系统特点

- **纯前端实现**：无需后端服务器，数据存储在浏览器本地
- **响应式设计**：支持桌面端、平板和移动设备
- **灵活的评价体系**：可自定义评价指标和权重
- **智能激励核算**：自动计算奖金分配
- **多年度数据管理**：支持多年度数据的存储和切换

### 1.3 技术架构

- **前端技术**：React 19.2.3 + TypeScript 5.8.2
- **构建工具**：Vite 6.2.0
- **数据存储**：浏览器本地存储 (localStorage)
- **UI组件**：Lucide React 图标库

## 2. 安装与部署

### 2.1 环境要求

- **操作系统**：Windows 10/11、macOS 10.15+、Linux
- **Node.js**：18.0.0 或更高版本
- **npm**：9.0.0 或更高版本
- **浏览器**：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+

### 2.2 安装步骤

1. **克隆或下载项目**

   ```bash
   git clone <仓库地址>
   # 或直接下载项目压缩包并解压
   ```

2. **安装依赖**

   ```bash
   cd Evaluation-Incentive-Distribution-System
   npm install
   ```

3. **启动开发服务器**

   ```bash
   npm run dev
   ```

   系统将在 http://localhost:3000 启动

4. **构建生产版本**

   ```bash
   npm run build
   ```

   构建产物将生成在 `dist` 目录

### 2.3 部署方式

- **本地部署**：直接在浏览器中打开 `dist/index.html` 文件
- **静态网站部署**：将 `dist` 目录上传到任何静态网站托管服务（如 GitHub Pages、Vercel、Netlify 等）

## 3. 系统登录与初始化

### 3.1 首次访问

1. 打开系统 URL（如 http://localhost:3000）
2. 系统会自动初始化，创建默认评价模板
3. 进入系统主界面，默认显示"总览看板"页面

### 3.2 系统初始化数据

首次访问时，系统会自动创建以下初始数据：

- 默认评价模板（包含基础标准、日常表现、年度贡献三个维度）
- 默认年度（当前年份和上一年份）
- 默认奖金计算方式（方式A：系数×月薪）

## 4. 系统功能操作指南

### 4.1 总览看板

总览看板展示当前年度的评价和激励分配情况，是系统的核心数据展示页面。

#### 4.1.1 功能说明

- **统计卡片**：显示已评价人数、累计分配系数、预算奖金支出
- **奖金计算设置**：可切换奖金计算方式，设置团队奖金总额
- **兼职人员资格设置**：可开启/关闭兼职人员的激励分配资格
- **激励分配明细**：展示所有人员的评价结果和奖金分配情况

#### 4.1.2 操作步骤

1. **选择年度**：在左侧导航栏选择要查看的年度
2. **设置奖金计算方式**：
   - 方式A：系数×月薪（基于个人月薪基数计算）
   - 方式B：比例分配（基于团队奖金总额按比例分配）
3. **设置团队奖金总额**：当选择方式B时，输入团队奖金总额
4. **设置兼职人员资格**：点击开关按钮开启或关闭兼职人员的激励分配资格
5. **查看分配明细**：在表格中查看所有人员的评价结果和奖金分配情况

### 4.2 人员基础资料管理

人员基础资料管理模块用于维护团队成员的基本信息，包括全职和兼职人员。

#### 4.2.1 功能说明

- **人员列表**：展示所有团队成员的基本信息
- **新增人员**：添加新的团队成员
- **编辑人员**：修改现有人员的信息
- **删除人员**：移除团队成员
- **调整顺序**：调整人员在列表中的顺序

#### 4.2.2 操作步骤

1. **新增人员**：
   - 点击右上角"新增人员"按钮
   - 填写人员信息（姓名、工号、入职日期、月薪基数、人员类型等）
   - 点击"保存信息"按钮

2. **编辑人员**：
   - 在人员列表中找到要编辑的人员
   - 点击右侧的编辑图标（铅笔图标）
   - 修改人员信息
   - 点击"保存信息"按钮

3. **删除人员**：
   - 在人员列表中找到要删除的人员
   - 点击右侧的删除图标（垃圾桶图标）
   - 系统会自动从列表中移除该人员

4. **调整人员顺序**：
   - 在人员列表中找到要调整顺序的人员
   - 点击上下箭头按钮调整顺序
   - 系统会自动保存新的顺序

### 4.3 评价模板管理

评价模板管理模块用于配置评价指标和权重，是系统的核心配置模块。

#### 4.3.1 功能说明

- **指标大类管理**：管理二级评价指标大类及其权重
- **三级指标管理**：管理每个大类下的三级评价指标及其权重
- **权重验证**：自动验证权重总和是否为100%

#### 4.3.2 操作步骤

1. **修改指标大类**：
   - 点击指标大类名称进行修改
   - 调整大类权重（输入数字，范围0-1）
   - 系统会自动验证权重总和是否为100%

2. **修改三级指标**：
   - 点击三级指标名称进行修改
   - 调整指标权重（输入数字，范围0-1）
   - 添加或修改指标描述
   - 系统会自动验证每个大类下的三级指标权重总和是否为100%

3. **添加三级指标**：
   - 在每个指标大类下方，点击"+ 新增三级评价指标"按钮
   - 输入新指标的名称、权重和描述
   - 系统会自动将新指标添加到该大类下

4. **删除三级指标**：
   - 在三级指标右侧，点击删除图标（垃圾桶图标）
   - 系统会自动从该大类下移除该指标

### 4.4 年度评价评分

年度评价评分模块用于对团队成员进行多维度的年度评价打分。

#### 4.4.1 功能说明

- **人员选择**：选择要评价的团队成员
- **模板选择**：选择适用的评价模板
- **多维度评分**：对各个评价指标进行打分（0-10分）
- **实时核算**：实时计算评价结果和激励系数
- **评分提交**：提交并保存评分结果

#### 4.4.2 操作步骤

1. **选择被考核人员**：
   - 在下拉菜单中选择要评价的人员
   - 系统会自动加载该人员的基本信息

2. **进行评分**：
   - 对每个三级指标进行打分（0-10分）
   - 可通过滑块或直接输入数字进行打分
   - 系统会自动计算加权总分和评价等级

3. **查看激励核算预览**：
   - 在右侧激励核算预览面板中查看评价结果
   - 包括年度加权总分、测算建议等级、激励分配资格等信息

4. **提交评分**：
   - 确认评分无误后，点击"提交并存档评分"按钮
   - 系统会自动保存评分结果并更新总览看板数据

### 4.5 年度管理

系统支持多年度数据的管理，可创建和切换不同年度的数据。

#### 4.5.1 功能说明

- **年度切换**：在不同年度之间切换
- **新增年度**：创建新的年度数据

#### 4.5.2 操作步骤

1. **切换年度**：
   - 在左侧导航栏的年度选择下拉菜单中选择要查看的年度
   - 系统会自动切换到该年度的数据

2. **新增年度**：
   - 在左侧导航栏的年度选择区域，点击"+"按钮
   - 系统会自动创建下一个年度的数据
   - 新年度会自动添加到年度选择下拉菜单中

## 5. 系统数据管理

### 5.1 数据存储方式

系统采用浏览器本地存储 (localStorage) 存储数据，数据存储在当前浏览器中，不会上传到任何服务器。

### 5.2 数据备份与恢复

#### 5.2.1 数据备份

1. **手动备份**：
   - 打开浏览器开发者工具（按F12）
   - 选择"Application"或"Storage"选项卡
   - 展开"Local Storage"，找到当前域名
   - 右键点击，选择"Copy all as JSON"
   - 打开记事本或其他文本编辑器，粘贴复制的内容
   - 保存文件为 `localStorage-backup.json`

2. **自动备份**：
   - 系统会在每次修改数据时自动保存到本地存储
   - 建议定期手动备份数据，以防浏览器数据丢失

#### 5.2.2 数据恢复

1. **手动恢复**：

   - 打开浏览器开发者工具（按F12）

   - 选择"Application"或"Storage"选项卡

   - 展开"Local Storage"，找到当前域名

   - 清空现有数据，然后右键点击，选择"Clear"

   - 打开开发者工具的"Console"选项卡

   - 运行以下代码（将 `<备份的JSON内容>` 替换为实际复制的内容）：

     ```javascript
     // 导入Local Storage数据
     const backupData = <备份的JSON内容>;
     for (const key in backupData) {
       if (Object.prototype.hasOwnProperty.call(backupData, key)) {
         localStorage.setItem(key, backupData[key]);
       }
     }
     console.log('Local Storage数据已导入');
     // 刷新页面以应用更改
     location.reload();
     ```

   - 按 `Enter` 键执行

   - 页面会自动刷新，加载恢复的数据

### 5.3 数据清除

如需清除所有模板数据，可执行以下操作：

1. 在浏览器地址栏输入 `javascript:localStorage.removeItem('eval_templates_v2');console.log('模板数据已清除，请刷新页面以应用初始模板');`
2. 按回车键执行
3. 刷新页面，系统会重新加载初始模板

## 6. 常见问题与解决方案

### 6.1 常见问题

| 问题                   | 可能原因               | 解决方案                                                |
| ---------------------- | ---------------------- | ------------------------------------------------------- |
| 页面加载后显示空白     | 浏览器兼容性问题       | 使用Chrome 90+、Firefox 88+、Edge 90+或Safari 14+浏览器 |
| 数据丢失               | 浏览器清除了本地存储   | 定期备份数据，使用相同浏览器访问系统                    |
| 权重验证失败           | 指标权重总和不等于100% | 调整指标权重，确保每个层级的权重总和为100%              |
| 兼职人员无激励分配资格 | 未开启兼职人员资格     | 在总览看板中开启兼职人员激励分配资格                    |
| 无法新增年度           | 系统权限问题           | 确保浏览器允许JavaScript执行，刷新页面后重试            |

### 6.2 错误提示与解决方法

- **"系统至少需保留一个激励评价模板"**：删除模板时，系统要求至少保留一个模板，确保系统正常运行
- **"确定要彻底删除整个评价模板及其关联的所有人员评分数据吗？此操作无法撤销。"**：删除模板时会同时删除该模板的所有评分数据，请谨慎操作
- **"二级汇总权重错误"**：指标大类的权重总和不等于100%，需要调整权重

## 7. 系统维护与支持

### 7.1 系统更新

当系统有新版本时，更新步骤如下：

1. 下载最新版本的系统文件
2. 替换现有文件（保留本地存储数据）
3. 刷新浏览器，系统会自动应用新版本

### 7.2 浏览器兼容性

系统支持以下浏览器：

- Google Chrome 90+
- Mozilla Firefox 88+
- Microsoft Edge 90+
- Apple Safari 14+

建议使用最新版本的Chrome浏览器以获得最佳体验。

### 7.3 性能优化

- **数据量较大时**：建议定期清理不需要的历史数据
- **浏览器卡顿**：可尝试刷新页面或清除浏览器缓存
- **加载缓慢**：检查网络连接，确保浏览器性能良好

## 9. 附录

### 9.1 系统术语解释

- **评价模板**：包含评价指标和权重的评价体系
- **二级指标**：评价模板中的大类指标（如基础标准、日常表现等）
- **三级指标**：每个二级指标下的具体评价点
- **权重**：指标在评价体系中的重要程度
- **激励系数**：根据评价结果计算的奖金分配系数
- **月薪基数**：用于计算奖金的个人月薪标准
